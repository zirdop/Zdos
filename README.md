# Zdos
## Fully Client Sided Google Extension!
(made for mac)

# How to set up:

1. Download the latest release as a zip file
2. Extract the zip file using the "Open" button
3. Go to chrome://extensions/
4. Make sure to have developer mode on!
5. Click "Load unpacked" and select the folder itself (the exctracted folder not the zip)
6. Go to the extensions button on google and pin "Zdos"
7. You are done! :D
(click the "Z" to open the gui and use stuff)
